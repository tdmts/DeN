Automatic Private IP Address (APIPA)

Als een computer ingesteld is als DHCP client verwacht deze een IP adres van de DHCP server. Dit gebeurt praktisch onmiddellijk wanneer de computer verbonden wordt met het netwerk. Als de DHCP server geen IP adres uitdeelt zal de computer zichzelf een Automatic Private IP Address (APIPA) toekennen.

Een APIPA adres moet toegekend worden omdat een systeem als IP adres 0.0.0.0 heeft voor het verbonden wordt met het netwerk. Zoals je weet is dit een ongeldig adres. Als de DHCP server geen IP adres uitdeelt blijft het systeem met dit adres zitten. Het is onmogelijk om met dit adres op het netwerk aangesloten te zijn, vandaar het zelf toegekende adres.

APIPA is de benaming die Microsoft geeft aan dit mechanisme. Het wordt ook wel auto-IP genoemd.

Een APIPA adres is een adres in het bereik van 169.254.1.0 tot 169.254.254.255 . Als je jouw IP instellingen nakijkt en je ziet dat jouw computer een adres heeft binnen dit bereik dan weet je dat je verbonden bent met het netwerk maar er waarschijnlijk geen communicatie mogelijk is met andere apparaten op het netwerk.
