Netwerk laag

Kernpunten
  • In de netwerk laag worden IP adressen gebruikt om adressering mogelijk te maken buiten het LAN.
  • De juiste terminologie voor data in de netwerk laag, transport laag en applicatie laag is nu pakket in plaats van frame.
  • Het apparaat dat gebruikt wordt om pakketten met een ander netwerk uit te wisselen op basis van IP adressen is een router.
  • Een computer kan een IP adres op twee manieren verkrijgen: statisch (door de gebruiker zelf ingevuld) en dynamisch (verkregen door de DHCP server of APIPA)
  • Omdat IP adressen moeilijk te onthouden zijn wordt soms gebruik gemaakt van domeinnamen zoals hogent.be .
  • Je kan nagaan als twee hosts in hetzelfde netwerk zitten door de AND bewerking uit te voeren op hun IP adres en subnetmasker.
  • In IPv4 zijn er drie private IP ranges: 10.x.x.y, 172.x.y.z en 192.168.x.y . Soms worden die nog opgedeeld in subnets voor veiligheid en performantie doeleinden.
  • De router maakt routing decisions met behulp van een routing table.
  • De default gateway is het IP adres naar waar een pakket zal gestuurd worden als het niet rechtstreeks kan bezorgd worden.
