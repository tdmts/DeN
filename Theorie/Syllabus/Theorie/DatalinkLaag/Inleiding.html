Inleiding

De tweede laag in het TCP/IP model is de datalink laag. In sommige literatuur wordt deze laag ook wel de network access laag genoemd.

In deze laag krijgen we een reeks 1en en 0en binnen vanuit de fysieke laag. Het is aan de datalink laag om deze om te zetten naar een leesbare boodschap of frame.

Hoe zo'n frame er precies uitziet en welke informatie je daarin kan terugvinden komt uitvoerig aan bod in dit hoofdstuk.

Voorlopig kan je onthouden dat de datalink laag zich focust op het uitwisselen van data tussen twee apparaten op hetzelfde netwerk. Eerst en vooral moet gecontroleerd worden als de data die we binnenkrijgen correct is. In de datalink laag zit dus een foutcontrole mechanisme ingebouwd. Daarna moeten we nagaan voor welk(e) appara(a)t(en) de data bestemd is. In de datalink laag zit er bijgevolg ook adresinformatie.
