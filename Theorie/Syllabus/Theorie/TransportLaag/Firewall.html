Firewall

  1. De ingebouwde Windows firewall op je computer is een
    • Host based firewall
    • Network based firewall
  2. Een network based firewall heeft een aantal nadelen maar waarom is het een goed idee om toch zo’n apparaat te hebben (staat niet in de tekst)?
     
    Omdat je de regel dan op één plaats zet in plaats van op iedere machine apart. Een host based firewall moet je op elke computer instellen en onderhouden, en hij beschermt alleen die ene computer. Een network based firewall staat op de grens van het netwerk en beschermt alles wat erachter hangt, ook de apparaten waarop je zelf niets kan instellen: printers, camera’s, een PLC. Hij blijft ook werken als een gebruiker zijn eigen firewall uitzet of als zijn machine besmet is.
  3. Je wil ervoor zorgen dat gebruikers in je LAN niet meer kunnen surfen naar externe websites. Welke firewall rule moet je instellen op de network based firewall?

    Schrap wat niet past en vul aan.

    ACCEPT / DENY / DROPINCOMING / OUTGOING
    PROTOCOL: TCP/ UDPPORT: _____
    DROP, OUTGOING, TCP, poort 80. Het verkeer vertrekt in het LAN en gaat naar buiten, dus OUTGOING. Webverkeer is TCP op poort 80. DROP en niet DENY: de tekst zegt dat de meeste firewalls alleen ACCEPT en DROP gebruiken, want een geweigerd pakket kost bandbreedte op de terugweg. Wil je ook HTTPS blokkeren, dan heb je er een tweede regel bij nodig voor poort 443.
