Simple Mail Transfer Protocol (SMTP)

Naast HTTP wordt e-mail ook heel vaak gebruikt om informatie uit te wisselen. Iedereen heeft al een e-mail verstuurd maar in de industrie wordt e-mail vaak gebruikt om een (kritische) status te rapporteren i.v.m. het productieproces.

Bij HTTP moet de gebruiker zelf een actie ondernemen (surfen naar een pagina) terwijl dit bij SMTP automatisch in de inbox terechtkomt. Je kan het vergelijken met een event.

Het is niet de bedoeling dat we het SMTP protocol volledig zullen bespreken. Het enige wat je moet onthouden is dat SMTP een eenvoudig tekstgebaseerd protocol is dat draait op TCP poort 25.

Met tekstgebaseerd bedoelen we dat we een mail kunnen versturen door in interactie te gaan met de mailserver en dat de boodschappen die we uitwisselen leesbaar zijn.

Je kan dus, in theorie, zelf een TCP verbinding openen via een programma zoals PuTTY met een mailserver. Het is echter makkelijker om, als je automatisch mail wil versturen, gebruik te maken van een code bibliotheek in PHP, ASP.Net, C# of NodeRed.

Mailservers worden echter beveiligd gezien ze misbruikt zouden kunnen worden voor spamdoeleinden. Als je een mailserver wil gebruiken dan heb je vaak een login en wachtwoord nodig en is het aantal mails dat je kan sturen op een dag soms beperkt.
