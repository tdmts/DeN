Inleiding – OSI model

  • OSI = Open Systems Interconnection (1979)
    • Set van afspraken ontwikkeld om communicatie tussen verschillende hardware mogelijk te maken => lagenmodel
ApplicationToepassingApplication PresentationVoorstelling dataPresentation SessionOpenen / sluiten verbindingSession TransportAfleveringTransport NetworkAddresseringNetwork Data linkFoutcontrole + addresseringData link PhysicalTransmissiemediaPhysical

Op bord

Transmissiemedia: kabel (coax, glasvezel, telefoonkabel, ethernetkabel)

Foutcontrole: CRC / pariteit | Adressering: binnen het lokaal netwerk (P-gebouw, B-gebouw, … klaslokalen, de persoon)

Adressering: buiten het lokaal netwerk (land, stad, straat + huisnummer)

Aflevering: gegarandeerd afleveren

Openen / sluiten: applicatie hoeft niet de verbinding constant open te houden (met meerdere tegelijk)

Voorstelling data: mp3, mp4, ASCII, … compressie, encryptie

Toepassing: welk protocol, bv. HTTP

Inleiding – TCP/IP model

  • Vereenvoudigd OSI model
    • Applicatie laag neemt Application, Presentation en Session over
  • OSI in de praktijk, praktisch ieder netwerkapparaat ondersteunt TCP/IP

Het is de verantwoordelijkheid van de applicatie (en dus de programmeur) om de verbinding te openen, een formaat te kiezen en een protocol te kiezen.

Bidirectionele communicatie

Voordelen?

+: Weinig kabel nodig, eenvoudig, goedkoop

Nadelen?

-: Wat als twee hosts op hetzelfde moment sturen? Collisions!

-: Alle hosts ontvangen elkaars data… veilig?

-: Wat als je de kabel onderbreekt? Complete failure!

Ring topologie

Repeaters die point to point met elkaar verbonden zijn

Repeater krijgt de data binnen, kopieert en stuurt door

Voordelen:

+: Unidirectioneel waardoor de kans op collisions verlaagt

+: Weinig kabel nodig, eenvoudig, goedkoop

Nadelen:

-: Alle hosts ontvangen elkaars data… veilig?

-: Latency...

Ster topologie

Een apparaat in het midden van het netwerk

Voordelen:

+: Fouten beperken zich tot 1 apparaat

+: Eenvoudig en relatief goedkoop

+: Privacy

Nadelen:

-: Als het centraal punt wegvalt is er geen communicatie meer mogelijk
