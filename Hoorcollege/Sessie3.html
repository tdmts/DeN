IPv4 header

  • Speciale adressen
    • 127.0.0.1 = localhost (iedere adapter heeft altijd dit adres)
    • 0.0.0.0 = non routable (= ongeldig / onbekend / nog niet toegekend)
    • 255.255.255.255 = broadcast (naar alle hosts in het netwerk)
    • 169.254.0.1 tot en met 169.254.255.254 = link local / APIPA (zelf toegekend)

IPv6 header

  • 128 bits adresruimte
    • 2^128 combinaties ~= 50 quadriljard IP adressen / persoon
    • 2001:0db8:85a3:0000:1319:8a2e:0370:7344

TCP/UDP

Private IP Range – /8 privaat LAN (Klasse A)

  • IP adres in de vorm van 10.X.X.Y
    • Netwerkdeel = ___ bits lang
    • Standaard SNM = ___ . ___ . ___ . ___ = ___ bits lang
    • Subnetdeel = ___ bits lang = ___ subnets
    • Hostdeel = ___ bits lang = __________ hosts

Eerste 8 bits staan vast op 0000 1010 (Netwerkdeel)

Standaard subnetmasker is 255.0.0.0 (/8)

Er is geen subnetdeel (netwerkdeel = lengte subnetmasker)

Overige 24 bits zijn vrij te kiezen (Hostdeel)

De twee hosts zitten in hetzelfde netwerk = ze kunnen elkaar zien

Private IP Range – /24 privaat LAN (Klasse C)

  • IP adres in de vorm van 192.168.X.Y
    • Netwerkdeel = ___ bits lang
    • Standaard SNM = ___ . ___ . ___ . ___ = ___ bits lang
    • Subnetdeel = ___ bits lang = ___ subnets
    • Hostdeel = ___ bits lang = __________ hosts

Het netwerkdeel is hier 16 bits lang! De eerste 16 bits (192.168) zijn VAST.

Standaard SNM = 255.255.255.0 = 24 bits lang

Het subnetdeel is dus 24 – 16 = 8 bits lang = 2^8 = 256 standaard subnets

Hostdeel = 8 bits lang = 254 hosts

Subnetten – praktisch

  • Je kan afwijken van het subnetmasker om het netwerk kleiner te maken

Private IP Range /8 privaat LAN

  • Je kan afwijken van het subnetmasker om het netwerk kleiner te maken
    • Subnetting ipv 255.0.0.0 bv. 255.255.255.0 ipv /8 bv. /24
    • Eerste 8 bits zijn netwerkdeel, 16 bits zijn subnetdeel, 8 bits zijn hostdeel
      • 32 – 8 – 8 = 16
      • Bv. 10.0.0.16
    • 2^16 = 65536 subnets
    • 2^8 -2 hosts = 254 hosts
      • -2: eerste en laatste adres mag je niet gebruiken

Je vertrekt hier van de vraag: hoeveel hosts wil ik onderbrengen in een subnet?

Hoeveel hosts wil ik scheiden van de andere hosts?

Hoe lang is mijn netwerk deel? Hoe lang is mijn host deel? Dan weet je het subnetdeel en hoeveel kleinere netwerkjes

je kan maken.

Private IP Range /24 privaat LAN

  • Je kan afwijken van het subnetmasker om het netwerk kleiner te maken
    • Subnetting ipv 255.255.255.0 bv. 255.255.255.128 ipv /24 bv. /25
    • Eerste 16 bits zijn netwerkdeel, 9 bits zijn subnetdeel, 7 bits zijn hostdeel
      • 11000000 10101000 00000000 00000001
    • 2^9 = 512 subnets
    • 2^7 - 2 hosts = 126 hosts
      • -2: eerste en laatste adres mag je niet gebruiken

Private IP Range /16 privaat LAN

  • Je kan afwijken van het subnetmasker om het netwerk kleiner te maken
    • Subnetting ipv 255.255.0.0 bv. 255.255.255.0 ipv /16 bv. /24
    • Eerste 12 bits zijn netwerkdeel, 12 bits zijn subnetdeel, 8 bits zijn hostdeel
      • 10101100 00010001 00000000 00000001
    • 2^12= 4096 subnetwerken
    • 2^8 - 2 hosts = 254 hosts
      • -2: eerste en laatste adres mag je niet gebruiken
